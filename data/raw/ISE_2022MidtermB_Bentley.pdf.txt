2) Consider the following description about a software for plotting and analysing scientific 
data from experiments using different chart types such as scatter, line etc. 
 
All the datasets from experiments will be kept in a research database. User can start 
plotting by selecting “plot data” option. Then the user will be provided with list of 
available datasets, based on the user credential. When the user selects a dataset from the 
list, system will show the columns in the dataset and a description. Then the user selects 
the chart type and provides which columns and rows of the dataset are to be plotted. User 
can select the colour style and provides the chart tiles also. If the colour style is not 
selected, a default style will be used. Once the chart information is provided, chart will be 
generated, displayed on the screen, and saved as a .png file as well. If the selected data 
contains non-numeric data, user will be prompted with the option to proceed with only 
the valid data and if user accepts this option, a plot will be generated only with the valid 
data. 
User needs to be logged into the system to do plotting or analysing data while the 
description of all experiments can be viewed by anyone. Issues can be occurred if the user 
does not have privileges to save the generated plots. If so, the system prompts the user to 
send an access right elevation request and if successful, the plot can be saved.
